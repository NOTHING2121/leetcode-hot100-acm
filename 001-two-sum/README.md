# 001. Two Sum

## 题目描述

给定整数数组和目标值 target，找出两个不同下标，使对应元素之和为 target。保证恰有一组答案。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 target。

## 输出描述

输出两个从 0 开始的下标，较小下标在前。

## 示例 1

输入：

```text
4
2 7 11 15
9
```

输出：

```text
0 1
```

## 示例 2

输入：

```text
3
3 2 4
6
```

输出：

```text
1 2
```

## 数据范围

2 <= n <= 100000；元素及 target 的绝对值不超过 10^9。
