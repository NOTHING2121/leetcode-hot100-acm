# 002. Group Anagrams

## 题目描述

将字符串分组：两个字符串当且仅当各字符出现次数相同才属于同组。重复字符串须保留。

## 输入描述

第一行输入字符串数量 n。

第二行输入 n 个字符串，以一个空格分隔。字符串仅含小写英文字母；空字符串用两个双引号 `""` 表示，这两个引号不属于字符串内容。

## 输出描述

第一行输出组数。随后每组占一行，组内字符串以一个空格分隔，不输出组内字符串数。空字符串同样用 `""` 表示。

组内字符串按字典序升序排列；各组按排序后的字符串序列的字典序升序排列：逐项比较首个不同字符串，前缀相同时较短序列在前。比较时 `""` 代表空字符串，排在所有非空字符串之前。

## 示例 1

输入：

```text
6
eat tea tan ate nat bat
```

输出：

```text
3
ate eat tea
bat
nat tan
```

## 示例 2

输入：

```text
1
a
```

输出：

```text
1
a
```

## 示例 3

输入：

```text
5
"" a "" a b
```

输出：

```text
3
"" ""
a a
b
```

## 数据范围

1 <= n <= 10000；每个字符串的实际长度为 0 到 100（不包括表示空字符串的引号）。
