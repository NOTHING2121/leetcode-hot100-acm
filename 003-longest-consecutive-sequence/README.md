# 003. Longest Consecutive Sequence

## 题目描述

求数组中由连续整数构成的最长序列长度。元素在原数组中的位置无需相邻，重复值只计一次。要求总时间为 O(n)。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。n = 0 时第二行为空行。

## 输出描述

输出最长长度；空数组输出 0。

## 示例 1

输入：

```text
6
100 4 200 1 3 2
```

输出：

```text
4
```

## 示例 2

输入：

```text
5
1 2 0 1 3
```

输出：

```text
4
```

## 数据范围

0 <= n <= 100000；-10^9 <= 元素 <= 10^9。
