# 004. Move Zeroes

## 题目描述

将数组中的所有 0 移到末尾，保持非零元素的相对顺序。须在原数组上修改，不得复制整个数组。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
5
0 1 0 3 12
```

输出：

```text
1 3 12 0 0
```

## 示例 2

输入：

```text
1
0
```

输出：

```text
0
```

## 数据范围

1 <= n <= 10000；元素为 32 位有符号整数。
