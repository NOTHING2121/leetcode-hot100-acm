# 005. Container With Most Water

## 题目描述

下标 i 处有高度为 h[i] 的竖线。选择两条竖线，与横轴围成容器；容量等于两线距离乘以较低高度。求最大容量。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最大容量。

## 示例 1

输入：

```text
9
1 8 6 2 5 4 8 3 7
```

输出：

```text
49
```

## 示例 2

输入：

```text
2
1 1
```

输出：

```text
1
```

## 数据范围

2 <= n <= 100000；0 <= h[i] <= 10000。
