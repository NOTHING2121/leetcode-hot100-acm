# 006. 3Sum

## 题目描述

找出数组中所有和为 0 的三元组。每组使用三个不同下标，按数值去重，相同数值的三元组只能出现一次。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

每行输出一个三元组，不输出结果数量。每个三元组内部非递减排列，三元组之间按字典序升序排列：从左到右比较首个不同元素，较小者在前；一方是另一方前缀时，较短者在前。无解时不输出任何内容。

## 示例 1

输入：

```text
6
-1 0 1 2 -1 -4
```

输出：

```text
-1 -1 2
-1 0 1
```

## 示例 2

输入：

```text
3
0 1 1
```

输出：

```text
```

## 数据范围

3 <= n <= 3000；-100000 <= 元素 <= 100000。
