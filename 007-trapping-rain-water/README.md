# 007. Trapping Rain Water

## 题目描述

相邻的 n 根柱子宽度均为 1，高度由数组给出。求降雨后这些柱子之间最多能存下多少单位的水。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出总水量。

## 示例 1

输入：

```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```

输出：

```text
6
```

## 示例 2

输入：

```text
1
5
```

输出：

```text
0
```

## 数据范围

1 <= n <= 20000；0 <= 高度 <= 100000。
