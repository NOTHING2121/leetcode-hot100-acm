# 008. Longest Substring Without Repeating Characters

## 题目描述

求字符串中不含重复字符的最长连续子串的长度。

## 输入描述

输入一整行字符串，可能为空，也可能包含空格；行结束符不属于字符串。

## 输出描述

输出最大长度。

## 示例 1

输入：

```text
abcabcbb
```

输出：

```text
3
```

## 示例 2

输入：

```text
bbbbb
```

输出：

```text
1
```

## 数据范围

0 <= 字符串长度 <= 50000；字符为可打印 ASCII 字符。
