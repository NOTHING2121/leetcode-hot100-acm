# 009. Find All Anagrams in a String

## 题目描述

给定 s 和 p，找出 s 中所有与 p 长度相等且各字符出现次数相同的连续子串。

## 输入描述

第一行输入 s，第二行输入 p，均仅含小写英文字母。

## 输出描述

输出这些子串在 s 中从 0 开始的起始下标，按升序排列，用空格分隔；没有结果输出 EMPTY。

## 示例 1

输入：

```text
cbaebabacd
abc
```

输出：

```text
0 6
```

## 示例 2

输入：

```text
ab
abc
```

输出：

```text
EMPTY
```

## 数据范围

1 <= |s|, |p| <= 30000。
