# 010. Subarray Sum Equals K

## 题目描述

求数组中元素之和恰好为 k 的非空连续子数组个数。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 k。

## 输出描述

输出个数。

## 示例 1

输入：

```text
3
1 1 1
2
```

输出：

```text
2
```

## 示例 2

输入：

```text
3
0 0 0
0
```

输出：

```text
6
```

## 数据范围

1 <= n <= 20000；-1000 <= 元素 <= 1000；-10^7 <= k <= 10^7。
