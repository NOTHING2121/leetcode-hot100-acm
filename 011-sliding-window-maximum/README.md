# 011. Sliding Window Maximum

## 题目描述

长度为 k 的窗口从数组最左端逐次向右移动一位，直到最右端。求每个窗口内的最大值。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 k。

## 输出描述

按窗口出现顺序输出 n-k+1 个最大值，用空格分隔。

## 示例 1

输入：

```text
8
1 3 -1 -3 5 3 6 7
3
```

输出：

```text
3 3 5 5 6 7
```

## 示例 2

输入：

```text
1
7
1
```

输出：

```text
7
```

## 数据范围

1 <= k <= n <= 100000；-10000 <= 元素 <= 10000。
