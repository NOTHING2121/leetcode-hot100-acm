# 012. Minimum Window Substring

## 题目描述

在 s 中寻找最短连续子串，使其包含 t 中每个字符至少相应次数。大小写不同视为不同字符。长度并列时取起始位置最小的子串。

## 输入描述

第一行输入 s，第二行输入 t，均由英文字母组成。

## 输出描述

输出所选子串；不存在时输出 EMPTY。

## 示例 1

输入：

```text
ADOBECODEBANC
ABC
```

输出：

```text
BANC
```

## 示例 2

输入：

```text
a
aa
```

输出：

```text
EMPTY
```

## 数据范围

1 <= |s|, |t| <= 100000。
