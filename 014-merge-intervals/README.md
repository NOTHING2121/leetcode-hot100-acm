# 014. Merge Intervals

## 题目描述

给定若干闭区间，合并所有有交集的区间，返回覆盖相同位置且互不相交的区间。端点相同也算相交。

## 输入描述

第一行输入 n，随后 n 行每行输入区间左右端点 l r。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。每行两个端点，按左端点升序输出。

## 示例 1

输入：

```text
4
1 3
2 6
8 10
15 18
```

输出：

```text
3
1 6
8 10
15 18
```

## 示例 2

输入：

```text
2
1 4
4 5
```

输出：

```text
1
1 5
```

## 数据范围

1 <= n <= 10000；0 <= l <= r <= 10000。
