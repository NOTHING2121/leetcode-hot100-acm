# 016. Product of Array Except Self

## 题目描述

构造数组 answer，使 answer[i] 等于原数组除下标 i 以外全部元素的乘积。不得使用除法，时间须为 O(n)，除输出数组外额外空间为 O(1)。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
4
1 2 3 4
```

输出：

```text
24 12 8 6
```

## 示例 2

输入：

```text
5
-1 1 0 -3 3
```

输出：

```text
0 0 9 0 0
```

## 数据范围

2 <= n <= 100000；-30 <= 元素 <= 30；所有前缀积、后缀积及答案都在 32 位有符号整数范围内。
