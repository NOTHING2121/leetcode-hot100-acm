# 018. Set Matrix Zeroes

## 题目描述

原矩阵中某个位置为 0 时，将该位置所在的整行和整列置为 0。所有判断均以修改前的矩阵为准。须原地修改，额外空间为 O(1)。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。

## 输出描述

输出结果矩阵，共 m 行，每行 n 个整数，用空格分隔。

## 示例 1

输入：

```text
3 3
1 1 1
1 0 1
1 1 1
```

输出：

```text
1 0 1
0 0 0
1 0 1
```

## 示例 2

输入：

```text
1 2
0 2
```

输出：

```text
0 0
```

## 数据范围

1 <= m,n <= 200；元素为 32 位有符号整数。
