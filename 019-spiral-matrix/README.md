# 019. Spiral Matrix

## 题目描述

从矩阵左上角开始，按向右、向下、向左、向上的顺时针方向逐层向内访问所有元素。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。

## 输出描述

按访问顺序输出所有元素，用空格分隔。

## 示例 1

输入：

```text
3 3
1 2 3
4 5 6
7 8 9
```

输出：

```text
1 2 3 6 9 8 7 4 5
```

## 示例 2

输入：

```text
1 3
4 5 6
```

输出：

```text
4 5 6
```

## 数据范围

1 <= m,n <= 10；-100 <= 元素 <= 100。
