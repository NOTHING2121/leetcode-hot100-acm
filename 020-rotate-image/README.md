# 020. Rotate Image

## 题目描述

将正方形矩阵顺时针旋转 90 度。必须原地修改，不能另建一个矩阵保存旋转结果。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。保证 m = n。

## 输出描述

输出结果矩阵，共 m 行，每行 n 个整数，用空格分隔。

## 示例 1

输入：

```text
2 2
1 2
3 4
```

输出：

```text
3 1
4 2
```

## 示例 2

输入：

```text
1 1
8
```

输出：

```text
8
```

## 数据范围

1 <= m = n <= 20；-1000 <= 元素 <= 1000。
