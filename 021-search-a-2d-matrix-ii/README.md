# 021. Search a 2D Matrix II

## 题目描述

矩阵每行从左到右升序排列，每列从上到下升序排列。判断目标值是否存在。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。最后一行输入 target。

## 输出描述

存在输出 true，否则输出 false。

## 示例 1

输入：

```text
3 3
1 4 7
2 5 8
3 6 9
6
```

输出：

```text
true
```

## 示例 2

输入：

```text
1 1
1
2
```

输出：

```text
false
```

## 数据范围

1 <= m,n <= 300；元素和 target 的绝对值不超过 10^9；允许相等的相邻元素。
