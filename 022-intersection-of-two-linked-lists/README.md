# 022. Intersection of Two Linked Lists

## 题目描述

两条无环单链表可能共享同一段尾链。请按节点身份找出第一个公共节点，不要把值相等当作节点相同。不得改变链表结构，要求 O(m+n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入 A 的节点数 n，第二行输入 n 个值；第三行输入 B 的节点数 m，第四行输入 m 个值；第五行输入 ia ib。ia = ib = -1 表示不相交；否则 A 从下标 ia、B 从下标 ib 起共享同一批节点，两段后缀的长度和值保证一致。下标从 0 开始。构造时必须复用共享节点，随后对两条链表执行查找，不能直接将构造参数作为查找结果。

## 输出描述

不相交输出 -1；否则输出首个公共节点在 A 中的下标。

## 示例 1

输入：

```text
5
4 1 8 4 5
6
5 6 1 8 4 5
2 3
```

输出：

```text
2
```

## 示例 2

输入：

```text
2
1 2
2
1 2
-1 -1
```

输出：

```text
-1
```

## 数据范围

1 <= n,m <= 30000；1 <= 节点值 <= 100000；相交时 0 <= ia < n，0 <= ib < m。
