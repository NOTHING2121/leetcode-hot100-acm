# 023. Reverse Linked List

## 题目描述

将单链表的 next 方向反转，返回新的头节点。请通过修改节点链接完成。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
5
1 2 3 4 5
```

输出：

```text
5 4 3 2 1
```

## 示例 2

输入：

```text
0

```

输出：

```text
EMPTY
```

## 数据范围

0 <= n <= 5000；-5000 <= 节点值 <= 5000。
