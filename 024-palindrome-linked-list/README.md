# 024. Palindrome Linked List

## 题目描述

判断单链表按 next 顺序读取的值是否正反相同。要求 O(n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。

## 输出描述

是回文输出 true，否则输出 false。

## 示例 1

输入：

```text
4
1 2 2 1
```

输出：

```text
true
```

## 示例 2

输入：

```text
2
1 2
```

输出：

```text
false
```

## 数据范围

1 <= n <= 100000；0 <= 节点值 <= 9。
