# 025. Linked List Cycle

## 题目描述

判断单链表是否存在沿 next 指针可重复到达同一节点的环。要求 O(1) 额外空间。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。第三行输入 pos。pos = -1 时尾节点指向空；否则尾节点的 next 指向从 0 开始的下标 pos 的节点。请先按此参数构造链表，判断过程只能使用头节点，不能直接以 pos 作为答案。

## 输出描述

有环输出 true，否则输出 false。

## 示例 1

输入：

```text
4
3 2 0 -4
1
```

输出：

```text
true
```

## 示例 2

输入：

```text
1
1
-1
```

输出：

```text
false
```

## 数据范围

0 <= n <= 10000；-100000 <= 节点值 <= 100000；pos = -1 或 0 <= pos < n。
