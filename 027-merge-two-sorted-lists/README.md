# 027. Merge Two Sorted Lists

## 题目描述

将两条按值非递减排列的单链表合并成一条非递减链表，使用原有节点重新连接。

## 输入描述

第一行输入 n，第二行输入第一条链表的 n 个值；第三行输入 m，第四行输入第二条链表的 m 个值。长度为 0 时对应值行为空行。请自行构造两条链表。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
3
1 2 4
3
1 3 4
```

输出：

```text
1 1 2 3 4 4
```

## 示例 2

输入：

```text
0

1
0
```

输出：

```text
0
```

## 数据范围

0 <= n,m <= 50；-100 <= 节点值 <= 100。
