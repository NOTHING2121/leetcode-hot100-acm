# 028. Add Two Numbers

## 题目描述

两条非空单链表分别表示两个非负整数，每个节点是一位十进制数字，低位在前。求两数之和，并以同样顺序构造结果链表。除数字 0 外，输入整数没有高位前导零。

## 输入描述

第一行输入 n，第二行输入第一条链表的 n 个值；第三行输入 m，第四行输入第二条链表的 m 个值。长度为 0 时对应值行为空行。请自行构造两条链表。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
3
2 4 3
3
5 6 4
```

输出：

```text
7 0 8
```

## 示例 2

输入：

```text
1
0
1
0
```

输出：

```text
0
```

## 数据范围

1 <= n,m <= 100；0 <= 节点值 <= 9。
