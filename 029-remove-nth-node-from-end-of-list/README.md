# 029. Remove Nth Node From End of List

## 题目描述

删除单链表从尾部数起的第 k 个节点，返回新的头节点。尾节点算第 1 个。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。第三行输入 k。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
5
1 2 3 4 5
2
```

输出：

```text
1 2 3 5
```

## 示例 2

输入：

```text
1
1
1
```

输出：

```text
EMPTY
```

## 数据范围

1 <= k <= n <= 30；0 <= 节点值 <= 100。
