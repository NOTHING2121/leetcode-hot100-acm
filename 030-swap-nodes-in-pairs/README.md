# 030. Swap Nodes in Pairs

## 题目描述

将单链表中相邻的两个节点两两交换，末尾单独一个节点保持不变。只能改变节点连接，不能交换节点值。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
4
1 2 3 4
```

输出：

```text
2 1 4 3
```

## 示例 2

输入：

```text
3
1 2 3
```

输出：

```text
2 1 3
```

## 数据范围

0 <= n <= 100；0 <= 节点值 <= 100。
