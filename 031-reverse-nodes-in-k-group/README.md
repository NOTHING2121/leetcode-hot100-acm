# 031. Reverse Nodes in k-Group

## 题目描述

从链表头开始，每 k 个节点为一组反转链接。最后不足 k 个的节点保持不变。不得修改节点值，要求 O(1) 额外空间。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。第三行输入 k。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
5
1 2 3 4 5
2
```

输出：

```text
2 1 4 3 5
```

## 示例 2

输入：

```text
3
1 2 3
3
```

输出：

```text
3 2 1
```

## 数据范围

1 <= k <= n <= 5000；0 <= 节点值 <= 1000。
