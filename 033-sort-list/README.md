# 033. Sort List

## 题目描述

将单链表按节点值非递减排序，返回排序后的头节点。请修改节点连接，要求 O(n log n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入节点数 n，第二行输入按 next 顺序排列的 n 个节点值；n = 0 时第二行为空行。请自行构造链表。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
4
4 2 1 3
```

输出：

```text
1 2 3 4
```

## 示例 2

输入：

```text
0

```

输出：

```text
EMPTY
```

## 数据范围

0 <= n <= 50000；-100000 <= 节点值 <= 100000。
