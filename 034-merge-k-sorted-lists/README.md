# 034. Merge k Sorted Lists

## 题目描述

合并 k 条非递减单链表，得到一条非递减单链表。请自行构造输入链表并合并节点。

## 输入描述

第一行输入 k。随后依次描述 k 条链表：先单独一行输入长度 n，再一行输入 n 个节点值；空链表的值行为空行。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
3
3
1 4 5
3
1 3 4
2
2 6
```

输出：

```text
1 1 2 3 4 4 5 6
```

## 示例 2

输入：

```text
0
```

输出：

```text
EMPTY
```

## 数据范围

0 <= k <= 10000；每条链表长度为 0 到 500；总节点数不超过 10000；节点值绝对值不超过 10000。
