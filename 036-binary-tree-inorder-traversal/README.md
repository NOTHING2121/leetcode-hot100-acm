# 036. Binary Tree Inorder Traversal

## 题目描述

输出二叉树的中序遍历：对每个节点先访问左子树，再访问该节点，最后访问右子树。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
4
1 null 2 3
```

输出：

```text
1 3 2
```

## 示例 2

输入：

```text
0

```

输出：

```text
EMPTY
```

## 数据范围

0 <= 实际节点数 <= 100；-100 <= 节点值 <= 100；输入为合法树序列。
