# 037. Maximum Depth of Binary Tree

## 题目描述

树的深度是根节点到最远叶节点路径上的节点数。求二叉树最大深度。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

输出最大深度；空树为 0。

## 示例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
```

## 示例 2

输入：

```text
0

```

输出：

```text
0
```

## 数据范围

0 <= 实际节点数 <= 10000；-100 <= 节点值 <= 100；输入为合法树序列。
