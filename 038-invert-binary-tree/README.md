# 038. Invert Binary Tree

## 题目描述

交换二叉树每个节点的左、右子树，得到原树的镜像。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

输出相同规则的层序序列，项之间用空格分隔，删除所有尾部 null；空树输出 EMPTY。输出不带项数。

## 示例 1

输入：

```text
7
4 2 7 1 3 6 9
```

输出：

```text
4 7 2 9 6 3 1
```

## 示例 2

输入：

```text
0

```

输出：

```text
EMPTY
```

## 数据范围

0 <= 实际节点数 <= 100；-100 <= 节点值 <= 100；输入为合法树序列。
