# 039. Symmetric Tree

## 题目描述

判断二叉树是否关于根节点左右对称，要求对应位置的结构和值都相同。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

对称输出 true，否则输出 false；空树视为对称。

## 示例 1

输入：

```text
7
1 2 2 3 4 4 3
```

输出：

```text
true
```

## 示例 2

输入：

```text
7
1 2 2 null 3 null 3
```

输出：

```text
false
```

## 数据范围

0 <= 实际节点数 <= 1000；-100 <= 节点值 <= 100；输入为合法树序列。
