# 040. Diameter of Binary Tree

## 题目描述

二叉树中任意两个节点之间的最长简单路径长度称为直径。长度按边数计算，路径无需经过根节点。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

输出直径。

## 示例 1

输入：

```text
5
1 2 3 4 5
```

输出：

```text
3
```

## 示例 2

输入：

```text
1
1
```

输出：

```text
0
```

## 数据范围

1 <= 实际节点数 <= 10000；-100 <= 节点值 <= 100；输入为合法树序列。
