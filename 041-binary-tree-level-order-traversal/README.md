# 041. Binary Tree Level Order Traversal

## 题目描述

按从上到下的层次访问二叉树，每层从左到右输出节点值。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

第一行输出层数，随后每层一行，值之间用空格分隔；空树只输出 0。

## 示例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
3
9 20
15 7
```

## 示例 2

输入：

```text
0

```

输出：

```text
0
```

## 数据范围

0 <= 实际节点数 <= 2000；-1000 <= 节点值 <= 1000；输入为合法树序列。
