# 042. Convert Sorted Array to Binary Search Tree

## 题目描述

将严格递增数组转换为高度平衡的二叉搜索树：任一节点左右子树的高度差不超过 1，左子树的值小于该节点，右子树的值大于该节点。为使答案唯一，要求每个节点的右子树节点数等于左子树节点数，或比左子树多 1。请实际构造树后输出。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出层序序列：非空节点依次提供左、右孩子，空位置为 null，空节点不提供孩子；删除末尾所有 null，项间用空格分隔，不输出项数。

## 示例 1

输入：

```text
5
-10 -3 0 5 9
```

输出：

```text
0 -10 5 null -3 null 9
```

## 示例 2

输入：

```text
1
7
```

输出：

```text
7
```

## 数据范围

1 <= n <= 10000；-10000 <= 元素 <= 10000；数组严格递增。
