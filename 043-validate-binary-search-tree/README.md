# 043. Validate Binary Search Tree

## 题目描述

判断二叉树是否满足：每个节点左子树的所有值严格小于该节点，右子树的所有值严格大于该节点。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

满足输出 true，否则输出 false。

## 示例 1

输入：

```text
3
2 1 3
```

输出：

```text
true
```

## 示例 2

输入：

```text
7
5 1 4 null null 3 6
```

输出：

```text
false
```

## 数据范围

1 <= 实际节点数 <= 10000；节点值为 32 位有符号整数；输入为合法树序列。
