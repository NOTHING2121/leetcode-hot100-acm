# 044. Kth Smallest Element in a BST

## 题目描述

给定所有节点值互异的二叉搜索树，求按值升序排列后的第 k 个节点值，k 从 1 开始。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。第三行输入 k。

## 输出描述

输出第 k 小的值。

## 示例 1

输入：

```text
3
3 1 4
1
```

输出：

```text
1
```

## 示例 2

输入：

```text
1
5
1
```

输出：

```text
5
```

## 数据范围

1 <= k <= 实际节点数 <= 10000；0 <= 节点值 <= 10000；输入为合法二叉搜索树。
