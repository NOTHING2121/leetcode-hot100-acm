# 046. Flatten Binary Tree to Linked List

## 题目描述

将二叉树原地展开：所有 left 指针置空，right 指针串起全部节点，顺序等于原树的前序遍历（根、左、右）。必须复用原节点，额外空间为 O(1)。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

沿展开后根节点的 right 链输出节点值，用空格分隔；空树输出 EMPTY。

## 示例 1

输入：

```text
7
1 2 5 3 4 null 6
```

输出：

```text
1 2 3 4 5 6
```

## 示例 2

输入：

```text
0

```

输出：

```text
EMPTY
```

## 数据范围

0 <= 实际节点数 <= 2000；-100 <= 节点值 <= 100；输入为合法树序列。
