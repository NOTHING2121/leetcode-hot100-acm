# 047. Construct Binary Tree from Preorder and Inorder Traversal

## 题目描述

给定同一棵二叉树的前序和中序遍历，重建该树。节点值互异，保证输入对应唯一合法二叉树。

## 输入描述

第一行输入节点数 n，第二行输入 n 个前序遍历值，第三行输入 n 个中序遍历值。

## 输出描述

输出层序序列，空位置为 null。非空节点依次提供左、右孩子，空节点不提供孩子；删除全部尾部 null，项间用空格分隔，不输出项数。

## 示例 1

输入：

```text
5
3 9 20 15 7
9 3 15 20 7
```

输出：

```text
3 9 20 null null 15 7
```

## 示例 2

输入：

```text
1
-1
-1
```

输出：

```text
-1
```

## 数据范围

1 <= n <= 3000；-3000 <= 节点值 <= 3000。
