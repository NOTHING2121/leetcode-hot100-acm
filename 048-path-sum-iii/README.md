# 048. Path Sum III

## 题目描述

统计二叉树中节点值之和等于 target 的非空路径数。路径只能从父节点向子节点延伸，可从任意节点开始，也可在任意节点结束。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。第三行输入 target。

## 输出描述

输出路径条数。

## 示例 1

输入：

```text
11
10 5 -3 3 2 null 11 3 -2 null 1
8
```

输出：

```text
3
```

## 示例 2

输入：

```text
1
0
0
```

输出：

```text
1
```

## 数据范围

0 <= 实际节点数 <= 1000；节点值绝对值不超过 10^9；target 的绝对值不超过 1000；输入为合法树序列。
