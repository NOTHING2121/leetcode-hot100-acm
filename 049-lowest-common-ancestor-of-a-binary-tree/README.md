# 049. Lowest Common Ancestor of a Binary Tree

## 题目描述

找出二叉树中指定两个不同节点的最近公共祖先，即同时包含两者的最深子树的根。节点可以是自身的祖先，所有节点值互异。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。第三行输入两个目标节点的值 p q，保证两者存在。

## 输出描述

输出最近公共祖先的节点值。

## 示例 1

输入：

```text
11
3 5 1 6 2 0 8 null null 7 4
5 1
```

输出：

```text
3
```

## 示例 2

输入：

```text
3
1 2 3
1 2
```

输出：

```text
1
```

## 数据范围

2 <= 实际节点数 <= 100000；节点值绝对值不超过 10^9；p != q；输入为合法树序列。
