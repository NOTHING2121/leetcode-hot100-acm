# 050. Binary Tree Maximum Path Sum

## 题目描述

在二叉树中选择一条非空简单路径，使节点值之和最大。路径可以在任意节点开始或结束，可经由父子连接转向，但不能重复经过节点。

## 输入描述

第一行输入序列项数 n（包含 null），第二行输入 n 个空格分隔的层序项，null 表示空节点。非空节点按出现顺序各接收后续两个项作为左、右孩子；空节点不再接收孩子。序列末尾省略的孩子均为空，禁止多余的尾部 null。空树用 n = 0 和一个空行表示。请自行构造二叉树。

## 输出描述

输出最大路径和。

## 示例 1

输入：

```text
7
-10 9 20 null null 15 7
```

输出：

```text
42
```

## 示例 2

输入：

```text
1
-3
```

输出：

```text
-3
```

## 数据范围

1 <= 实际节点数 <= 30000；-1000 <= 节点值 <= 1000；输入为合法树序列。
