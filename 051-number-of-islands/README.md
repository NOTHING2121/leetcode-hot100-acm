# 051. Number of Islands

## 题目描述

网格中 1 表示陆地，0 表示水。通过上下左右相邻陆地相连的区域算一个岛屿；网格外都是水。求岛屿数量。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。

## 输出描述

输出岛屿数量。

## 示例 1

输入：

```text
3 3
1 1 0
0 1 0
0 0 1
```

输出：

```text
2
```

## 示例 2

输入：

```text
1 2
0 0
```

输出：

```text
0
```

## 数据范围

1 <= m,n <= 300；元素只能为 0 或 1。
