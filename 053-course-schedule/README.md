# 053. Course Schedule

## 题目描述

共有 n 门课程，编号为 0 到 n-1。每条先修关系 u v 表示必须先完成 u 才能学习 v。判断是否能完成全部课程。

## 输入描述

第一行输入 n 和先修关系数 m，随后 m 行每行输入 u v，表示有向边 u 到 v。

## 输出描述

可以完成输出 true，否则输出 false。

## 示例 1

输入：

```text
2 1
0 1
```

输出：

```text
true
```

## 示例 2

输入：

```text
2 2
0 1
1 0
```

输出：

```text
false
```

## 数据范围

1 <= n <= 2000；0 <= m <= 5000；0 <= u,v < n；关系不重复。
