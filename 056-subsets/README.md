# 056. Subsets

## 题目描述

给定互不相同的整数，输出所有不同子集，包含空集。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。每个子集内部升序排列，空集用 EMPTY 表示。子集之间按字典序升序排列：从左到右比较首个不同元素，较小者在前；一方是另一方前缀时，较短者在前。排序时 EMPTY 代表空序列，排在最前。

## 示例 1

输入：

```text
2
1 2
```

输出：

```text
4
EMPTY
1
1 2
2
```

## 示例 2

输入：

```text
1
0
```

输出：

```text
2
EMPTY
0
```

## 数据范围

1 <= n <= 10；-10 <= 元素 <= 10；元素互不相同。
