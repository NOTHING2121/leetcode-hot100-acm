# 057. Letter Combinations of a Phone Number

## 题目描述

数字与字母对应关系为 2:abc、3:def、4:ghi、5:jkl、6:mno、7:pqrs、8:tuv、9:wxyz。为输入的每个数字选择一个对应字母，求按原数字顺序组成的全部字符串。

## 输入描述

输入一行数字字符串，可以为空行。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。字符串按字典序升序输出；输入为空时只输出 0。

## 示例 1

输入：

```text
23
```

输出：

```text
9
ad
ae
af
bd
be
bf
cd
ce
cf
```

## 示例 2

输入：

```text

```

输出：

```text
0
```

## 数据范围

0 <= 字符串长度 <= 4；非空字符均为 2 到 9。
