# 058. Combination Sum

## 题目描述

给定互不相同的正整数和目标 target。每个整数可使用任意次，找出所有总和为 target 的不同组合，组合内顺序不构成区别。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 target。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。每个组合内部非递减排列，组合之间按字典序升序排列：从左到右比较首个不同元素，较小者在前；一方是另一方前缀时，较短者在前。无解只输出 0。

## 示例 1

输入：

```text
4
2 3 6 7
7
```

输出：

```text
2
2 2 3
7
```

## 示例 2

输入：

```text
1
2
1
```

输出：

```text
0
```

## 数据范围

1 <= n <= 30；2 <= 元素 <= 40；1 <= target <= 40；答案数量不超过 150。
