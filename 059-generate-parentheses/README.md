# 059. Generate Parentheses

## 题目描述

生成由 n 对圆括号组成的所有合法括号字符串。合法表示每个左括号均可与其后一个右括号配对，配对正确嵌套。

## 输入描述

输入一个整数 n。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。字符串按字典序升序输出，左括号小于右括号。

## 示例 1

输入：

```text
3
```

输出：

```text
5
((()))
(()())
(())()
()(())
()()()
```

## 示例 2

输入：

```text
1
```

输出：

```text
1
()
```

## 数据范围

1 <= n <= 8。
