# 060. Word Search

## 题目描述

判断能否在字符网格中沿上下左右相邻位置依次拼出给定单词。同一路径不能重复使用任何格子。

## 输入描述

第一行输入 m n，随后 m 行每行输入 n 个空格分隔的英文字母，最后一行输入单词 word。

## 输出描述

存在输出 true，否则输出 false。

## 示例 1

输入：

```text
3 4
A B C E
S F C S
A D E E
ABCCED
```

输出：

```text
true
```

## 示例 2

输入：

```text
1 1
A
AA
```

输出：

```text
false
```

## 数据范围

1 <= m,n <= 6；1 <= |word| <= 15；字符均为英文字母，区分大小写。
