# 061. Palindrome Partitioning

## 题目描述

将字符串切分为若干非空连续片段，使每个片段正反读都相同。输出所有切分方案，片段连接后必须等于原字符串。

## 输入描述

输入一个仅含小写英文字母的非空字符串 s。

## 输出描述

第一行输出结果数量，随后每行输出一个结果。每行按原位置顺序输出各片段，以空格分隔。方案按片段字符串序列的字典序升序排列，先比较首个不同片段，前缀相同时较短序列在前。

## 示例 1

输入：

```text
aab
```

输出：

```text
2
a a b
aa b
```

## 示例 2

输入：

```text
a
```

输出：

```text
1
a
```

## 数据范围

1 <= |s| <= 16。
