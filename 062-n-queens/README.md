# 062. N-Queens

## 题目描述

在 n×n 棋盘放置 n 个皇后，使任意两个皇后不在同一行、同一列或同一斜线上。输出全部摆放方案。

## 输入描述

输入一个整数 n。

## 输出描述

第一行输出方案数，随后每行用 n 个整数表示一组方案，第 i 个整数表示第 i 行皇后所在列，行列都从 0 编号。方案按整数序列的字典序升序输出；无解只输出 0。

## 示例 1

输入：

```text
4
```

输出：

```text
2
1 3 0 2
2 0 3 1
```

## 示例 2

输入：

```text
2
```

输出：

```text
0
```

## 数据范围

1 <= n <= 9。
