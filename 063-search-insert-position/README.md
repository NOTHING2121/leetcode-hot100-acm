# 063. Search Insert Position

## 题目描述

在严格递增数组中查找 target。存在时返回下标，否则返回插入后仍保持递增的插入位置。下标从 0 开始，允许插在末尾。要求 O(log n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 target。

## 输出描述

输出位置。

## 示例 1

输入：

```text
4
1 3 5 6
5
```

输出：

```text
2
```

## 示例 2

输入：

```text
4
1 3 5 6
7
```

输出：

```text
4
```

## 数据范围

1 <= n <= 10000；元素及 target 的绝对值不超过 10000。
