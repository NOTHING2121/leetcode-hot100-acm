# 064. Search a 2D Matrix

## 题目描述

矩阵每行非递减排列，且每行第一个元素严格大于上一行最后一个元素。判断 target 是否存在，要求 O(log(m*n)) 时间。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。最后一行输入 target。

## 输出描述

存在输出 true，否则输出 false。

## 示例 1

输入：

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

输出：

```text
true
```

## 示例 2

输入：

```text
1 1
1
0
```

输出：

```text
false
```

## 数据范围

1 <= m,n <= 100；元素及 target 的绝对值不超过 10000。
