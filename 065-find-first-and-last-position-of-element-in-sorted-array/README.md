# 065. Find First and Last Position of Element in Sorted Array

## 题目描述

求 target 在非递减数组中第一次和最后一次出现的位置。下标从 0 开始，要求 O(log n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。n = 0 时第二行为空行。第三行输入 target。

## 输出描述

输出首次和末次位置；不存在输出 -1 -1。

## 示例 1

输入：

```text
6
5 7 7 8 8 10
8
```

输出：

```text
3 4
```

## 示例 2

输入：

```text
0

1
```

输出：

```text
-1 -1
```

## 数据范围

0 <= n <= 100000；元素及 target 的绝对值不超过 10^9。
