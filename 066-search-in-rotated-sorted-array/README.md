# 066. Search in Rotated Sorted Array

## 题目描述

一个严格递增数组经过若干次循环移动后得到当前数组。求 target 在当前数组中的下标，从 0 开始。要求 O(log n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 target。

## 输出描述

存在输出下标，否则输出 -1。

## 示例 1

输入：

```text
7
4 5 6 7 0 1 2
0
```

输出：

```text
4
```

## 示例 2

输入：

```text
1
1
0
```

输出：

```text
-1
```

## 数据范围

1 <= n <= 5000；元素及 target 的绝对值不超过 10000；数组元素互异。
