# 067. Find Minimum in Rotated Sorted Array

## 题目描述

一个严格递增数组经过若干次循环移动后得到当前数组，求当前数组的最小元素。要求 O(log n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最小值。

## 示例 1

输入：

```text
5
3 4 5 1 2
```

输出：

```text
1
```

## 示例 2

输入：

```text
1
7
```

输出：

```text
7
```

## 数据范围

1 <= n <= 5000；元素绝对值不超过 5000；数组元素互异。
