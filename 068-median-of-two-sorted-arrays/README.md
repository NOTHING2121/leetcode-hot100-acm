# 068. Median of Two Sorted Arrays

## 题目描述

给定两个非递减整数数组，求合并后全部元素的中位数。元素总数为偶数时，中位数为中间两个数的平均值。要求 O(log(m+n)) 时间。

## 输入描述

第一行输入 n，第二行输入第一个数组的 n 个值；第三行输入 m，第四行输入第二个数组的 m 个值。空数组的值行为空行。

## 输出描述

输出中位数，固定保留 1 位小数。

## 示例 1

输入：

```text
2
1 3
1
2
```

输出：

```text
2.0
```

## 示例 2

输入：

```text
2
1 2
2
3 4
```

输出：

```text
2.5
```

## 数据范围

0 <= n,m <= 1000；1 <= n+m <= 2000；元素绝对值不超过 10^6。
