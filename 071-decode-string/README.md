# 071. Decode String

## 题目描述

解码形如 k[片段] 的字符串，含义是将括号内解码后的内容重复 k 次。可以嵌套，括号外的字母按原样保留。保证编码语法合法。

## 输入描述

输入一行编码字符串 s。

## 输出描述

输出完整解码结果。

## 示例 1

输入：

```text
3[a2[c]]
```

输出：

```text
accaccacc
```

## 示例 2

输入：

```text
abc
```

输出：

```text
abc
```

## 数据范围

1 <= |s| <= 30；字符由小写英文字母、数字及方括号组成；1 <= k <= 300；数字仅用于重复次数；解码结果长度不超过 100000。
