# 072. Daily Temperatures

## 题目描述

给定每日温度，计算每一天至少还要等待几天才会出现更高温度。必须严格高于当天温度。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出 n 个等待天数，找不到更高温度的位置输出 0，元素以空格分隔。

## 示例 1

输入：

```text
8
73 74 75 71 69 72 76 73
```

输出：

```text
1 1 4 2 1 1 0 0
```

## 示例 2

输入：

```text
3
30 30 30
```

输出：

```text
0 0 0
```

## 数据范围

1 <= n <= 100000；30 <= 温度 <= 100。
