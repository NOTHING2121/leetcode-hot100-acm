# 073. Largest Rectangle in Histogram

## 题目描述

相邻柱子的宽度均为 1，高度由数组给出。求完全位于柱形覆盖区域内且边与坐标轴平行的最大矩形面积。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最大面积。

## 示例 1

输入：

```text
6
2 1 5 6 2 3
```

输出：

```text
10
```

## 示例 2

输入：

```text
1
0
```

输出：

```text
0
```

## 数据范围

1 <= n <= 100000；0 <= 高度 <= 10000。
