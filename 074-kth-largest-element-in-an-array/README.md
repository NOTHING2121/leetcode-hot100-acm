# 074. Kth Largest Element in an Array

## 题目描述

求数组按非递增顺序排列后的第 k 个元素，重复元素分别占据位置。要求平均 O(n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 k。

## 输出描述

输出第 k 大的值。

## 示例 1

输入：

```text
6
3 2 1 5 6 4
2
```

输出：

```text
5
```

## 示例 2

输入：

```text
4
2 2 1 3
3
```

输出：

```text
2
```

## 数据范围

1 <= k <= n <= 100000；元素绝对值不超过 10000。
