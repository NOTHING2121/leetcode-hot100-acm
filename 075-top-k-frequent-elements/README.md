# 075. Top K Frequent Elements

## 题目描述

找出数组中出现次数最多的 k 个不同整数。保证入选元素集合唯一；当 k 小于不同整数总数时，第 k 高的频次严格大于第 k+1 高的频次。要求时间优于 O(n log n)。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。第三行输入 k。

## 输出描述

将入选的 k 个整数按数值升序输出，以空格分隔。

## 示例 1

输入：

```text
6
1 1 1 2 2 3
2
```

输出：

```text
1 2
```

## 示例 2

输入：

```text
1
7
1
```

输出：

```text
7
```

## 数据范围

1 <= n <= 100000；元素绝对值不超过 10000；1 <= k <= 不同整数的数量。
