# 077. Best Time to Buy and Sell Stock

## 题目描述

数组表示每天的股票价格。最多买入一次并在之后某一天卖出一次，求最大利润；允许不交易。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最大利润。

## 示例 1

输入：

```text
6
7 1 5 3 6 4
```

输出：

```text
5
```

## 示例 2

输入：

```text
5
7 6 4 3 1
```

输出：

```text
0
```

## 数据范围

1 <= n <= 100000；0 <= 价格 <= 10000。
