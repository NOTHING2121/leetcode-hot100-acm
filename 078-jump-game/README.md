# 078. Jump Game

## 题目描述

从数组下标 0 出发，位置 i 的非负整数表示从这里最多可向右跳的距离。判断能否到达最后一个位置。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

可到达输出 true，否则输出 false。

## 示例 1

输入：

```text
5
2 3 1 1 4
```

输出：

```text
true
```

## 示例 2

输入：

```text
5
3 2 1 0 4
```

输出：

```text
false
```

## 数据范围

1 <= n <= 10000；0 <= 元素 <= 100000。
