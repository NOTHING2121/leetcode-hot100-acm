# 079. Jump Game II

## 题目描述

从数组下标 0 出发，位置 i 的非负整数表示从这里最多可向右跳的距离。保证能到达末尾，求最少跳跃次数。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最少次数；只有一个元素时输出 0。

## 示例 1

输入：

```text
5
2 3 1 1 4
```

输出：

```text
2
```

## 示例 2

输入：

```text
1
0
```

输出：

```text
0
```

## 数据范围

1 <= n <= 10000；0 <= 元素 <= 1000。
