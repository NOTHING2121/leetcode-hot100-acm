# 080. Partition Labels

## 题目描述

将字符串分成尽可能多的非空连续片段，使每个字母只出现在其中一个片段。所有片段按原顺序连接后应等于原字符串。

## 输入描述

输入仅含小写英文字母的一行字符串 s。

## 输出描述

按从左到右的顺序输出各片段长度，用空格分隔。

## 示例 1

输入：

```text
ababcbacadefegdehijhklij
```

输出：

```text
9 7 8
```

## 示例 2

输入：

```text
eccbbbbdec
```

输出：

```text
10
```

## 数据范围

1 <= |s| <= 500。
