# 082. Pascal's Triangle

## 题目描述

输出杨辉三角的前 n 行。第 1 行为一个 1；每行首尾为 1，其他位置等于上一行左上方与右上方两个数之和。

## 输入描述

输入一个整数 n。

## 输出描述

输出 n 行，第 i 行输出 i 个整数，以空格分隔，行号从 1 开始。

## 示例 1

输入：

```text
5
```

输出：

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

## 示例 2

输入：

```text
1
```

输出：

```text
1
```

## 数据范围

1 <= n <= 30。
