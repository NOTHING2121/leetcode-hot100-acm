# 085. Coin Change

## 题目描述

给定若干种硬币面额，每种数量无限。求凑出总额 amount 所需的最少硬币数。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。数组元素表示面额。第三行输入 amount。

## 输出描述

无法凑出输出 -1，否则输出最少硬币数；amount 为 0 时输出 0。

## 示例 1

输入：

```text
3
1 2 5
11
```

输出：

```text
3
```

## 示例 2

输入：

```text
1
2
3
```

输出：

```text
-1
```

## 数据范围

1 <= n <= 12；1 <= 面额 <= 2^31-1；面额互不相同；0 <= amount <= 10000。
