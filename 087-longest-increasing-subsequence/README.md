# 087. Longest Increasing Subsequence

## 题目描述

从数组中按原顺序保留若干元素，形成严格递增序列。保留的位置不必连续，求能得到的最长长度。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最长长度。

## 示例 1

输入：

```text
8
10 9 2 5 3 7 101 18
```

输出：

```text
4
```

## 示例 2

输入：

```text
3
7 7 7
```

输出：

```text
1
```

## 数据范围

1 <= n <= 2500；-10000 <= 元素 <= 10000。
