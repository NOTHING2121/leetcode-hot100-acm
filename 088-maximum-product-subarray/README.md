# 088. Maximum Product Subarray

## 题目描述

求数组所有非空连续子数组中最大的元素乘积。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出最大乘积。

## 示例 1

输入：

```text
4
2 3 -2 4
```

输出：

```text
6
```

## 示例 2

输入：

```text
3
-2 0 -1
```

输出：

```text
0
```

## 数据范围

1 <= n <= 20000；-10 <= 元素 <= 10；任意连续子数组的乘积均在 32 位有符号整数范围内。
