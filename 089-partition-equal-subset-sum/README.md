# 089. Partition Equal Subset Sum

## 题目描述

判断能否将数组中的元素分成两个子集，使两者的元素和相等。每个位置的元素必须且只能分到其中一个子集。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

可以输出 true，否则输出 false。

## 示例 1

输入：

```text
4
1 5 11 5
```

输出：

```text
true
```

## 示例 2

输入：

```text
4
1 2 3 5
```

输出：

```text
false
```

## 数据范围

1 <= n <= 200；1 <= 元素 <= 100。
