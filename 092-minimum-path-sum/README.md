# 092. Minimum Path Sum

## 题目描述

网格每个位置有一个非负整数。从左上角走到右下角，每步只能向右或向下，求经过位置的最小总和，包含起点与终点。

## 输入描述

第一行输入行数 m 和列数 n，随后 m 行每行输入 n 个整数。

## 输出描述

输出最小总和。

## 示例 1

输入：

```text
3 3
1 3 1
1 5 1
4 2 1
```

输出：

```text
7
```

## 示例 2

输入：

```text
1 1
5
```

输出：

```text
5
```

## 数据范围

1 <= m,n <= 200；0 <= 元素 <= 200。
