# 094. Longest Common Subsequence

## 题目描述

给定两个字符串，求两者最长公共子序列的长度。子序列通过删除任意数量字符且保持其余字符相对顺序得到，不要求连续。

## 输入描述

第一行输入 s，第二行输入 t。

## 输出描述

输出最大长度；没有共同字符时输出 0。

## 示例 1

输入：

```text
abcde
ace
```

输出：

```text
3
```

## 示例 2

输入：

```text
abc
def
```

输出：

```text
0
```

## 数据范围

1 <= |s|,|t| <= 1000；字符为小写英文字母。
