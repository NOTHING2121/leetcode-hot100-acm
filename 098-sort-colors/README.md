# 098. Sort Colors

## 题目描述

数组元素只可能是 0、1、2。原地重排数组，使所有 0 在前，所有 1 居中，所有 2 在后。不得调用库排序函数，要求 O(n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
6
2 0 2 1 1 0
```

输出：

```text
0 0 1 1 2 2
```

## 示例 2

输入：

```text
1
1
```

输出：

```text
1
```

## 数据范围

1 <= n <= 300；元素为 0、1 或 2。
