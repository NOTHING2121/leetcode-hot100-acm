# 099. Next Permutation

## 题目描述

把数组视为整数排列，修改为使用相同元素的字典序紧邻的下一个不同排列；不存在更大排列时改为字典序最小排列。字典序比较首个不同位置的整数。必须原地修改，额外空间为 O(1)。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出结果序列，元素之间用一个空格分隔；空序列输出 EMPTY。

## 示例 1

输入：

```text
3
1 2 3
```

输出：

```text
1 3 2
```

## 示例 2

输入：

```text
3
3 2 1
```

输出：

```text
1 2 3
```

## 数据范围

1 <= n <= 100；0 <= 元素 <= 100；允许重复元素。
