# 100. Find the Duplicate Number

## 题目描述

给定长度为 n+1 的数组，所有元素都在 1 到 n 之间。恰好一种数值重复出现两次或更多次，其他数值至多出现一次。找出重复值。不得修改数组，要求 O(n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入数组长度 m，第二行输入 m 个整数；其中 n = m-1。

## 输出描述

输出重复的数值。

## 示例 1

输入：

```text
5
1 3 4 2 2
```

输出：

```text
2
```

## 示例 2

输入：

```text
5
3 3 3 3 3
```

输出：

```text
3
```

## 数据范围

2 <= m <= 100001；1 <= 元素 <= m-1。
