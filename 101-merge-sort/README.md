# 101. Merge Sort

## 题目描述

给定整数数组，使用归并排序将其按升序排列。不得调用库排序函数，要求 O(n log n) 时间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出排序后的序列，元素之间用一个空格分隔。

## 示例 1

输入：

```text
6
5 2 3 1 4 2
```

输出：

```text
1 2 2 3 4 5
```

## 示例 2

输入：

```text
4
-3 10 -3 0
```

输出：

```text
-3 -3 0 10
```

## 数据范围

1 <= n <= 100000；元素绝对值不超过 10^9。
