# 102. Quick Sort

## 题目描述

给定整数数组，使用快速排序原地将其按升序排列。不得调用库排序函数，要求期望 O(n log n) 时间。测试数据可能包含已有序、逆序或大量重复元素的数组。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出排序后的序列，元素之间用一个空格分隔。

## 示例 1

输入：

```text
5
3 1 4 1 5
```

输出：

```text
1 1 3 4 5
```

## 示例 2

输入：

```text
6
7 7 7 7 7 7
```

输出：

```text
7 7 7 7 7 7
```

## 数据范围

1 <= n <= 100000；元素绝对值不超过 10^9。
