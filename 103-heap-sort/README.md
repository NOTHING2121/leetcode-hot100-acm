# 103. Heap Sort

## 题目描述

给定整数数组，使用堆排序原地将其按升序排列。不得调用库排序函数或使用库中的优先队列，要求 O(n log n) 时间和 O(1) 额外空间。

## 输入描述

第一行输入数组长度 n，第二行输入 n 个整数。

## 输出描述

输出排序后的序列，元素之间用一个空格分隔。

## 示例 1

输入：

```text
7
9 4 7 1 8 2 6
```

输出：

```text
1 2 4 6 7 8 9
```

## 示例 2

输入：

```text
1
42
```

输出：

```text
42
```

## 数据范围

1 <= n <= 100000；元素绝对值不超过 10^9。
